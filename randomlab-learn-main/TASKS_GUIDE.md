# Инструкция по работе с задачами

## Структура задач

Задачи в проекте разделены на два типа:

### 1. Симуляторные задачи (5 шт.)
**Расположение:** Отображаются внутри уроков  
**Файл:** `src/data/tasks.ts` → `SIMULATOR_TASKS`  
**Признак:** Имеют поле `simulatorHint`  
**Эмодзи:** 🔬

**Список:**
- id: 9 (randomness-intro)
- id: 16 (simulation)
- id: 24 (simulation)
- id: 40 (simulation)
- id: 33 (simulation)

### 2. Обычные задачи (35 шт.)
**Расположение:** Отдельная страница `/tasks`  
**Файл:** `src/data/tasks.ts` → `REGULAR_TASKS`  
**Признак:** Без `simulatorHint`

## Как добавить новую задачу

### Симуляторная задача (для урока)

```typescript
// В массив SIMULATOR_TASKS
{
  id: 41,
  lessonSlug: 'название-урока',
  level: 'Симулятор',
  text: `Текст задачи...`,
  solution: `Решение...`,
  simulatorHint: 'Подсказка для симулятора', // ОБЯЗАТЕЛЬНО!
}
```

### Обычная задача (для раздела "Дополнительные задачи")

```typescript
// В массив REGULAR_TASKS
{
  id: 42,
  lessonSlug: 'название-урока',
  level: 'ЕГЭ базовый', // или 'ОГЭ', 'ЕГЭ профильный', 'ЕГЭ повышенный'
  text: `Текст задачи...`,
  solution: `Решение...`,
  // simulatorHint НЕ указывать!
}
```

## API функции

```typescript
// Получить симуляторные задачи для урока
getSimulatorTasksByLesson(slug: string): Task[]

// Получить обычные задачи для урока
getRegularTasksByLesson(slug: string): Task[]

// Получить все задачи для урока (устаревшая, для совместимости)
getTasksByLesson(slug: string): Task[]
```

## Компоненты

### TasksBlock (в уроках)
- Показывает только симуляторные задачи
- Использует `getSimulatorTasksByLesson()`
- Заголовок: "Задачи с симулятором 🔬"

### TasksPage (отдельная страница)
- Показывает все обычные задачи
- Фильтрация по уровню и теме
- Маршрут: `/tasks`

## Навигация

1. **Главное меню (Navbar):**
   - Главная
   - Уроки
   - **Задачи** ← новая ссылка
   - Эксперименты

2. **Сайдбар уроков:**
   - Список уроков
   - 🎲 Открыть эксперименты
   - **📝 Дополнительные задачи** ← новая кнопка

## Запуск проекта

```bash

npm install

# Сборка

```

## Проверка изменений

После изменения задач проверьте:

1. ✅ Сборка проходит без ошибок: `npm run build`
2. ✅ Симуляторные задачи отображаются в уроках
3. ✅ Обычные задачи отображаются на странице `/tasks`
4. ✅ Фильтры работают корректно
5. ✅ Навигация работает (меню, сайдбар, breadcrumbs)
